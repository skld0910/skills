# Skills

A collection of reusable Claude Code skills.

## Available skills

| Skill | Description | Install |
|-------|-------------|---------|
| [design](design/SKILL.md) | Load brand design systems (73 brands) | `npx skills add <user>/skills --skill design` |

## Usage

```bash
# Install a skill
npx skills add <user>/skills --skill design

# In Claude Code, use it as:
/design airbnb
/design stripe
```
